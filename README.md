## What is NODE ZERO?

You are Employee #0000 — the one glitch in a system that controls everything. Fight through 4 floors of a corrupt corporate network, neutralize the hive-mind, and face The Director in the final confrontation.

But even if you win... the loop may never end.🔁

## How to Play

| Input | Action |
|-------|--------|
| `WASD` / Arrow Keys | Move |
| Mouse | Aim |
| Left Click | Shoot |
| `Q` | GLITCH — freeze nearby enemies |
| `E` | STATIC DASH — phase through walls |
| `R` | GHOST — deploy decoy, go invisible |
| `F` | ??? — find the hidden terminal |

**Goal:** Clear 75% of enemies on each floor, reach the glowing exit. Survive The Director.

## The Themes

**Locked & Linked**🔒🖇️ — Every enemy is connected to nearby enemies via a visible hive-mind network. Shoot one, and damage chains through the links to hit all connected enemies simultaneously.

**Pattern Breaker**⛓️‍💥 — Each enemy type follows a distinct movement pattern. Drones circle. Managers flank. The Enforcer has no pattern — that's the point. Read the patterns, then break them.

**Light the Path**💡 — The office is dark. Your character carries a point light. Every explosion spawns an expanding ring of light. The more you fight, the more you illuminate the path forward.

## The Boss — THE DIRECTOR

A three-phase fight in a circular arena. Each phase changes the movement pattern:
- **Phase 1** — Circular orbit
- **Phase 2** — Figure-8 + clone decoys
- **Phase 3** — Chaos. Walls glitch. No safe strategy.

Die during the boss and something unexpected happens.

## Built With

- **Three.js** (r128) — 3D WebGL rendering
- **Vanilla JavaScript** — no frameworks
- **HTML / CSS** — UI and overlays
- Ships as a **single `index.html`** file

---

## Technical Highlights

- Procedural floor generation via random walk algorithm
- Hive-mind implemented as a real-time distance graph with chain-reaction propagation
- Orthographic isometric camera with raycaster mouse aiming
- Polar coordinate boss arena boundary enforcement
- Parametric movement curves for boss phases (circle → Lissajous figure-8 → chaotic noise)
- Dual-canvas architecture: 2D Matrix rain behind WebGL game layer
