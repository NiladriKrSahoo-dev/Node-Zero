# NODE ZERO👾
Built for Xpecto'26 GameJam — IIT Mandi📍

Themes: Locked & Linked · Pattern Breaker · Light the Path

## How to Play🚀
Open index.html in any browser. Or play live: [https://niladrikrsahoo-dev.github.io/Node-Zero/]

WASD — Move | Mouse — Aim | Click — Shoot
Q — Glitch | E — Dash | R — Ghost

You may get blocked by the map somewhere by a single block. You can use the dash ability to phase through walls.
